# 多环境自动化部署的一次收敛

## 背景（Situation）

多套环境（开发/测试/预发/生产）部署逻辑分散且各自演化，新人很难一次性跑通。

## 目标（Task）

收敛到一份统一的部署脚本，环境差异用变量驱动。

## 行动（Action）

mongo 安装

```
docker run -d -p 27017:27017 --name mongodb -e MONGO_INITDB_ROOT_USERNAME=admin -e MONGO_INITDB_ROOT_PASSWORD=***REDACTED*** -v $PWD/db://opt/app/bigmw/mongodb/data hub.bigitom.com/mongo:4.4.3
```

解压文件

```
tar -zxvf autoexec.tar.gz
```

复制文件到mongo容器

```
docker cp autoexec  9fecabbc8c31:/autoexec/
```

进入mongo 容器

```
docker exec -it <ID>
```

进入复制容器的目录

```
#初始化mongodb数据  
mongorestore --db power_demo --authenticationDatabase admin --username admin --password Admin@1234 autoexec/
```

## 收获（Result）

新环境从零到部署完成的时间从 1 天缩短到 1 小时，部署文档也只需要维护一份。
