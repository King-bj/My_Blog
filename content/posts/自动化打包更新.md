# 自动化打包更新流水线落地

## 背景（Situation）

每次版本发布都要手动打包、上传、解压、重启，操作分散在多人手里，容易漏步骤。

## 目标（Task）

把整个流程脚本化 + Jenkins 化，做到一键发布。

## 行动（Action）

## 打包
先打包runer-base
docker build -t hub.bigitom.com/runner-base:1.1.1 -f DockerfileRunnerPythonV2 .
再打包runner
docker build -t hub.bigitom.com/power-runner:6.4.2 -f DockerfileV2 .  

保存runner到tar文件

docker save -o power-runner.tar hub.bigitom.com/power-runner:6.4.2
hub.bigitom.com/power-log-schedule:B-V6.4.2
服务器解压runner文件
docker load -i  power-runner.tar

服务器删除旧runer镜像
docker stop <runnerid>

服务器启动新runer镜像
docker run -d -p 8084:8084 -p 8888:8888 hub.bigitom.com/power-runner:6.4.0

## 收获（Result）

发布周期从 2 小时缩到 15 分钟，发布过程零差错运行了大半年。
