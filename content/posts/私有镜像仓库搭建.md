# Harbor 私有镜像仓库搭建实战

## 背景（Situation）

公司网络隔离，无法直接拉公网镜像；并且要求所有镜像都要在内网留存以便审计。

## 目标（Task）

搭一个稳定可用的私有镜像仓库（Harbor），并接入 CI 流水线。

## 行动（Action）

docker run -itd -v /data/registry:/var/lib/registry -p 5000:5000 --restart=always --name registry registry:latest
docekr ps

docker inspect <registry服务名称>
获取到docker容器ip段
ipconfig 查看本机和docker容器Ip相同的ip
docker desktop修改设置中的docker engine为：
{
  "builder": {
    "gc": {
      "defaultKeepStorage": "20GB",
      "enabled": true
    }
  },
  "experimental": false,
  "insecure-registries": [
    "localhost:5000"
  ],
  "registry-mirrors": [
    "https://dockerproxy.com"
  ]
}

docker pull 172.27.96.1:5000/power-log-schedule:6.2.0 --platform linux/arm64

docker save -o power-log-schedule-6.2.0-arm64.tar 172.27.96.1:5000/power-log-schedule:6.2.0

## 收获（Result）

镜像拉取速度从分钟级提升到秒级，安全审计也终于有了完整的镜像清单。
